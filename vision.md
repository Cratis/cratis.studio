# The Vision

The grand vision of Cratis Studio is to build a software development tool aimed for the post AI era.
We believe that there is a clear fork in the road with the introductions of LLMs.
The only issue is that the LLMs are trained on source code written for humans by humans.
It is also trained on a wide variation of quality in this realm.

We believe in being opinionated and actually see taking away choices as a bit of a blessing.
With the foundation in event modeling and vertical slices and backed up with a platform that is
opinionated, we have all the building blocks to create a new approach to software development,
one that marries decades of software development with the latest and greatest.

Human in the loop is more important than ever, we believe the human element should instead be
moved to focus on the design of the software, deciding how workflows fit together, what constitutes business value
and how things look and feel. This is what Cratis Studio should help with.

With event sourcing being at the core of the Cratis platform, any solutions built on top will be
event sourced.

Part of the vision is also to be able to go from a prompt that tells what the software one is trying to build
to then a generated event model and then press "play" within a couple of minutes, and then iterate.
AI infused all the way, you ask for changes, you talk to specialized agents as if they're your team members.
The specialized agents can then be trained to know your domain or be partners that you use for different purposes.

Part of our full story is to democratize event sourcing, as we do believe all information systems should be written
using event sourcing - so that one does not lose valuable data, data that can be used for new capabilities, data that
can be used for training ML models - helping achieve your business goals, faster.

We need something that kinda tells that the plan is also to give people the options of putting in the custom code when absolutely needed,
since we can't cover it all. And also generate to code that can be maintained. Cratis Studio also takes the role of project management
to a certain degree, with status of slices being an important part. Also quality and regression is taken care of with the
Given When Then type of specifications that are actually runnable. Collaboration is at the heart as well, multiple users
working on the same thing together at the same time, and with full chat capabilities with the cross "breed" (<- better word)
communication with humans and agents in the loop.
